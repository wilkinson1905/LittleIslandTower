# 詳細設計：Little Island Tower

## 構成
`dollhouse-maker` のエンジンを流用する。`src/*.js` をつなげて `dollhouse.html` にする。

- `00_core.js`：描画の基本と光の焼き込み。階数に応じて物体を選んで焼き直す
- `10_tower.js`：塔、屋根、小塔、空と海
- `11_floor1.js`、`12_floor2.js`、`13_floor3.js`：各階の部屋
- `14_island.js`：島の地面と飾り
- `20_sprites.js`：動物と小物のスプライト
- `30_timeline.js`：動物のストーリー
- `40_fx.js`：動く要素
- `45_game.js`：育成の状態、操作、画面、セーブ
- `50_main.js`：描画ループ

## 主要な判断
- 塔の平面は画面上で幅140、奥行き70の六角形、階の高さは100。正面を切り開き、奥の3面の壁を見せる。屋根は壁に直接のるベル形で、階が増えると一番上へ移る
- 六角形の壁は箱の前後関係で並べられないので、描く順番を階ごとの層で決める
- 物体に `level`（その階数以上で出す）と `only`（その階数のときだけ出す）を持たせ、階が増えるときに焼き直す。切り替えは雲で隠す
- 背景の動きは時刻と進行状況だけで決まる。育成の状態は別に持ち、ループの検証は進行を固定して行う
- 物体に `furn`（買ったら出す）を持たせ、買ったときに焼き直す。各階の寝床は `furn` を持たないので最初からある
- 動物の予定はブロックの開始時に階数と家具を読んで作る。家具を買っても再生中のブロックは変えず、次のブロックから使う。動物が瞬間移動しないようにするため
- カニの反応は動物の予定から読むので、絵は時刻と進行状況だけで決まるまま
- 動物の予定はブロックの開始時に「誰がいるか」も読み、相手がいれば交流、いなければ一人の行動にする。誰がいるかが変わるのは塔が伸びたときと、留守のあとに新しいペットが来たときだけなので、再生中のブロックが不自然に変わらない
- 雨の日の行動はブロックのシードで決める（外に残るか、雨のあとに窓辺へ行くか外へ行くか）。同じシードなら同じ行動になり、ループの検証が保たれる
- 風船は開いている間だけ `advance()` で進むゲームの要素で、検証用の全部入りの絵には出ない
- カタログの絵は、その家具の物体だけを部屋と同じ描画処理で描いて切り抜く。風鈴、モビール、ランタン、金魚ばちの一部は動く層にしかないので、動く層の描画を取り込む
- 強調表示はフレームの合成後に、全体を少し暗くし、家具の部分だけ元の明るさに戻して、輪郭を光らせる

## テスト
- `tools/verify.mjs`：スキルの完了条件。全部入りの状態で調べる
- `tools/game_test.mjs`：セーブと再開、留守の分、最初から完成までの通し

## 決まった数値

自動テストの模擬プレイで調整した値。実機で遊んだ感想で変える可能性がある。

- シーグラス：10秒ごとに1個、浜に最大12個。青1（72%）、緑2（23%）、琥珀5（5%）。平均で毎分約8.7個
- 閉じている間：45秒ごとに1個。小びんの容量は10個から始まり、15、30、50、80個で20、30、45、60個に増える
- 風船：最初は3分後、以後は4〜6分ごと。約30秒で横切る。プレゼントの中身は15個（40%）、25個（44%）、50個（16%）で平均25個
- 階の値段：2階120個、3階300個
- 雨：約40秒。ドラゴンは80%で外へ、ねこ、こいぬ、うさぎ、ひつじは15%で外に残る
- 家具：全23種、4〜30個、合計310個。各階の寝床（ねこ、こいぬ、うさぎ）は最初からある。ドラゴンは来るときに自分のいすを持ってくる
- おやつ：貝がらクッキー5個（なつき+1）、ラムネアイス12個（+2）。おもちゃ：ビーチボール8個（+2）、かざぐるま15個（+3）
- なつき度は0〜10で、ハートは2ごとに1つ。4と8で新しいしぐさを覚える
- 窓辺のおやつ：10個。次に開いたとき、ちびドラゴン、くものひつじ、ペンギンの順に1匹ずつ来る
- 模擬プレイでの完成時間（風船も拾う）：何も買わず集め続けて約32分、集めた分の3分の1を使うと約48分、半分弱を動物、家具、小びんに使うと約60分

## 動物の居場所

左の柱に沿ったはしごで、階と地面と屋根をつなぐ。1階は正面からも外へ出られる。ひつじとドラゴンは飛んで出る。

- 家：1階 ねこ、くものひつじ／2階 こいぬ、ちびドラゴン／3階 うさぎ／桟橋 ペンギン
- 出かける先：屋根、やしの木、砂浜、桟橋の先、ひまわり畑、潮だまり、デッキチェア
- ヤシの葉は8枚が別々に、先端だけゆっくり揺れる。全体を距離で動かすと、1ピクセルずれる境目が円になって伸び縮みして見えるため
- ストーリー：カニにちょっかい（crab）、船を眺める（boat）、天気雨と虹（rainbow）、木登り（palm）、屋根（roof）、浜辺（beach）。室内だけの play、perch、snack、quiet も残す

## 交流

各ストーリーに1組の交流を割り当てる。相手がいなければ、そのストーリーの一人の行動に戻る。

| ストーリー | 交流 | 組 |
|---|---|---|
| beach | 鼻をつけてあいさつ | ねこ、こいぬ |
| play | 追いかけっこ | ねこ、こいぬ |
| perch | 寄り添って昼寝 | ねことうさぎ（いなければ、ねことこいぬ） |
| quiet | 寄り添って昼寝 | こいぬ、ひつじ |
| crab | ねこがこいぬを誘ってカニへ | ねこ、こいぬ |
| snack | 火を吹き、雨で消す | ドラゴン、ひつじ（いなければ、ねことこいぬのあいさつ） |
| boat、roof、rainbow、showcase | 並んで眺める | ねこ、こいぬ |
| palm | 木の上のねこに、こいぬがほえる | ねこ、こいぬ |

## 雨の日

rainbow と showcase が雨のストーリー。降り始める前に動物を外へ出しておき、雨で室内へ急ぐ様子が見えるようにする。

- 外で虹を眺める場所は、虹が塔に隠れないところ：桟橋の先、デッキチェア、屋根。塔の真正面と真後ろには行かない
- 自動テストで、多数のシードについて雨の間の居場所の割合と、虹を眺める場所を確かめる
